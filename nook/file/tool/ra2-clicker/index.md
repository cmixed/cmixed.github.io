红色警戒2自动连点器，用于自动执行快速点击操作。

## 下载

前往 [GitHub Releases](https://github.com/cmixed/ra2-clicker/releases) 下载最新版本。

## 功能特点

- 支持自定义点击间隔
- 支持热键启停
- 轻量级，占用资源少
- 绿色免安装

## 使用说明

1. 下载并运行 `ra2-clicker.exe`
2. 设置点击间隔（毫秒）
3. 设置启动/停止热键
4. 按热键开始自动点击
5. 再次按热键停止

## 注意事项

- 仅适用于 Windows 系统
- 请合理使用，避免影响游戏平衡
- 建议在单机模式下使用
