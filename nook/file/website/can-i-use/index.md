Can I Use 是一个前端开发工具，用于查询 Web 技术（如 HTML、CSS、JavaScript API）在各浏览器中的兼容性。

## 主要功能

- 查询 CSS、HTML、JS API 的浏览器支持情况
- 按浏览器版本筛选
- 全球使用统计
- 支持功能组合查询

## 使用场景

- 前端开发时确认技术方案可行性
- 查找 polyfill 或降级方案
- 了解目标用户的浏览器环境
